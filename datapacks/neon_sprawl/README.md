# Neon Sprawl datapack

This directory is the destination for the Lost Cities datapack namespace and generated assets.

Expected layout:

```
neon_sprawl/
  pack.mcmeta
  data/
    neoncity/
      lostcities/
        palettes/
        parts/
        buildings/
        multibuildings/
        citystyles/
        worldstyles/
```

The earlier v0.1 Neon Sprawl design is the baseline to restore here: cyan/magenta/amber vanilla palettes, corporate towers, vertical slum stacks, 2x2 arcologies, and a dense intact-city profile. Do not copy unvalidated generated JSON into this folder. Verify every registry schema against Lost Cities 1.21.1 first.
