# Source schematics

The workflow in `.github/workflows/sync-schematics.yml` imports Sponge `.schem` files from [Reference/Schems1/schemmys](https://github.com/exiledmajor/Reference/tree/main/Schems1/schemmys).

Original files are retained here. Duplicate contents are excluded from the synchronized set and recorded in the workflow log. Legacy `.schematic` and Bedrock `.mcstructure` files are intentionally excluded pending separate format-specific conversion.
